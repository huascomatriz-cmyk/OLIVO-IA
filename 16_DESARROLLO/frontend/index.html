Modo DEMO y modo LIVE

El sistema es híbrido: siempre abre, con o sin conexión.

🟡 Modo DEMO

Funciona sin Supabase, usando los datos embebidos en el dashboard (504 olivos + monitoreo simulado). Ideal para presentar sin depender de internet ni credenciales.

🔵 Modo LIVE

Funciona con Supabase: el mapa carga desde la RPC arbol_geojson y los monitoreos se registran con la RPC registrar_monitoreo, actualizando el estado real de cada árbol.

⚠ Regla operacional: la demo nunca modifica directamente la tabla arbol. Todo cambio de estado ocurre exclusivamente vía la RPC registrar_monitoreo (con security definer y RLS).
