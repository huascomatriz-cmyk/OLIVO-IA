# Logo BRUZZONE IA — v02 (kit de marca)

**v02 · 2026-05-29.** Versión refinada del logotipo, con variantes y exportaciones listas para uso.

## Ajustes aplicados respecto a v01

- **Kerning de la línea inferior** "TERRITORIO · IA · PRECISIÓN" corregido: espaciado uniforme entre palabras y **gaps balanceados a cada lado de los bullets** (se eliminó el apretado "IA · PRECISIÓN").
- **Tracking general** de la bajada ajustado para lectura premium.
- **Equilibrio del bloque:** la línea inferior se **centra bajo el wordmark**, no alineada a la izquierda.
- **Alineación horizontal** del isotipo y el texto centrada verticalmente.
- **Peso visual del isotipo** equilibrado: su diámetro ≈ alto del bloque de texto (wordmark + bajada), para que ninguno domine.

- **Versión transparente:** el PNG *horizontal* y el *cuadrada* tienen fondo transparente (RGBA); úsalos sobre cualquier superficie.
- **SVG:** fuente vectorial, escala infinita y editable (titulares serif; en la web se renderiza con la fuente del sistema).
- **PNG:** renderizados a alta resolución (≈4×) para nitidez; el favicon incluye tamaños estándar y `.ico`.

## Uso recomendado

- **Web / claro:** horizontal transparente o fondo claro.
- **Cabeceras oscuras / fotos:** fondo oscuro (texto blanco + IA dorada).
- **Sellos, grabados, una tinta:** monocromático / isotipo mono.
- **App / pestaña navegador:** `favicon.ico` y `favicon_32`; **iOS/Apple touch:** `favicon_180`; **PWA:** `favicon_512`.
- **Redes (avatar):** cuadrada o favicon_512.
